# Tools

내가 사용하는 도구들을 기록하는 프로젝트입니다.

## 📖 Overview

이 저장소는 개발, 디자인, 생산성 향상 등 다양한 분야에서 사용하는 도구들을 체계적으로 문서화하기 위한 프로젝트입니다.

## 📂 Structure

```
tools/
├── README.md          # 프로젝트 소개 및 안내
├── INDEX.md           # 전체 도구 인덱스
├── TEMPLATE.md        # 새 도구 추가 시 사용할 템플릿
└── tools/             # 카테고리별 도구 문서
    ├── development.md # 개발 도구
    ├── productivity.md # 생산성 도구
    ├── design.md      # 디자인 도구
    └── devops.md      # DevOps 도구
```

## 🚀 Quick Start

1. **도구 찾기**: [INDEX.md](INDEX.md)에서 전체 도구 목록을 확인하세요
2. **카테고리 탐색**: `tools/` 디렉토리에서 카테고리별 도구를 확인하세요
3. **도구 추가**: [TEMPLATE.md](TEMPLATE.md)를 참고하여 새 도구를 추가하세요

## 📝 How to Contribute

새로운 도구를 추가하려면:

1. 적절한 카테고리 파일 선택 (예: `tools/development.md`)
2. [TEMPLATE.md](TEMPLATE.md) 형식에 따라 도구 정보 작성
3. 필요한 경우 `INDEX.md`에 도구 이름 추가

## 📋 Categories

- **💻 Development**: IDE, 버전 관리, API 개발 도구
- **🚀 Productivity**: 노트, 작업 관리, 커뮤니케이션 도구
- **🎨 Design**: UI/UX, 그래픽, 일러스트레이션 도구
- **⚙️ DevOps**: 컨테이너, CI/CD, 모니터링 도구
