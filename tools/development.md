## Version Control

### Git
- **용도**: 버전 관리 시스템
- **홈페이지**: https://git-scm.com/
- **설치 방법**: `brew install git` (macOS) 또는 공식 웹사이트
- **주요 명령어**:
  - `git init`: 저장소 초기화
  - `git clone`: 원격 저장소 복제
  - `git commit`: 변경사항 커밋

## API Development

### Postman
- **용도**: API 개발 및 테스트
- **홈페이지**: https://www.postman.com/
- **주요 기능**:
  - REST API 테스트
  - API 문서화
  - 자동화된 테스트
