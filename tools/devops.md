# DevOps Tools

DevOps 및 인프라 관리에 사용하는 도구들을 기록합니다.

## Container & Orchestration

### Docker
- **용도**: 컨테이너 플랫폼
- **홈페이지**: https://www.docker.com/
- **설치 방법**: 공식 웹사이트에서 Docker Desktop 다운로드
- **주요 명령어**:
  - `docker build`: 이미지 빌드
  - `docker run`: 컨테이너 실행
  - `docker compose`: 멀티 컨테이너 애플리케이션 관리

### Kubernetes
- **용도**: 컨테이너 오케스트레이션
- **홈페이지**: https://kubernetes.io/
- **주요 기능**:
  - 자동 스케일링
  - 로드 밸런싱
  - 자가 치유

## CI/CD

### GitHub Actions
- **용도**: CI/CD 자동화
- **홈페이지**: https://github.com/features/actions
- **주요 기능**:
  - 자동화된 빌드 및 테스트
  - 배포 자동화
  - 워크플로우 관리

## Monitoring

### Prometheus
- **용도**: 모니터링 및 알림
- **홈페이지**: https://prometheus.io/
- **주요 기능**:
  - 시계열 데이터베이스
  - 쿼리 언어 (PromQL)
  - 알림 규칙 설정
