# Productivity Tools

생산성 향상을 위해 사용하는 도구들을 기록합니다.

## Note Taking

### Notion
- **용도**: 노트 작성 및 문서 관리
- **홈페이지**: https://www.notion.so/
- **주요 기능**:
  - 마크다운 지원
  - 데이터베이스 기능
  - 협업 기능

## Task Management

### Todoist
- **용도**: 할 일 관리
- **홈페이지**: https://todoist.com/
- **주요 기능**:
  - 프로젝트 기반 작업 관리
  - 우선순위 설정
  - 반복 작업 지원

## Communication

### Slack
- **용도**: 팀 커뮤니케이션
- **홈페이지**: https://slack.com/
- **주요 기능**:
  - 채널 기반 대화
  - 파일 공유
  - 다양한 통합 지원
